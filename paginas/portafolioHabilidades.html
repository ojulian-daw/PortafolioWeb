Mis Habilidades

Trabajo principalmente en desarrollo web, combinando frontend y backend según las necesidades de cada proyecto. Me interesa construir sitios y aplicaciones funcionales, mantener el código organizado y evitar complejidad innecesaria.

HTML & CSS

Desarrollo sitios web a medida utilizando HTML y CSS, cuidando la estructura, el diseño responsive y la adaptación a distintos tamaños de pantalla.

JavaScript

Utilizo JavaScript para añadir interactividad y lógica a los sitios web, desde pequeñas funcionalidades de interfaz hasta aplicaciones con una mayor cantidad de comportamiento dinámico.

PHP

Desarrollo aplicaciones y sitios web con PHP, incluyendo la creación de funcionalidades del lado del servidor y paneles de administración.

SQL

Trabajo con bases de datos SQL para almacenar consultar y gestionar la información de las aplicaciones web.

WordPress

Desarrollo sitios con WordPress procurando mantener una instalación ligera y utilizar únicamente los plugins y recursos necesarios para cada proyecto.

Phaser 3

Utilizo Phaser 3 para desarrollar pequeños juegos web con JavaScript, trabajando con escenas, sprites, eventos, movimiento y lógica de juego.

Bootstrap

Utilizo Bootstrap para desarrollar interfaces responsive de forma rápida, aprovechando su sistema y componentes para aportar utilidad al proyecto.

SEO

Aplico técnicas de SEO técnico y optimización web para mejorar la estructura, el rendimiento y la accesibilidad de los sitios, facilitando su rastreo e indexación.
