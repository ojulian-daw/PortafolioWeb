Juegos JavaScript con Phaser 3

Juego de la cucaracha

Juego creado con JavaScript y con el framework de Phaser 3.
Es un juego hecho para mejorar mis conocimientos de programación con uso de de un framework para ayudarme a manejar las escenas y las colisiones de los elementos de los canvas.
El juego trata de una cucaracha que tiene que ir comiendo alimento para crecer y esquivar a los insectos mas grandes que ella, a medidad que va creciendo podrá comerse a otros personajes que van apareciendo por la pantalla.

Juego del caos

Juego creado también con el framework de Phaser 3. Hecho para seguir mejorando mi nivel de programación con JavaScript y el uso de escenas y control de niveles.
El juego consiste en un dinosaurio que debe destruir todo lo que hay a su paso y defenderse de las fuerzas militares que intentan detenerle.

Prácticas con PHP y SQL

Ejercicio de gestor de gastos

Este ejercicio realizo con PHP y SQL sirvio para mejorar mis conociminetos y nivel de programación en la parte de backend.

Puedes insertar el gasto o el tipo según su ingreso mediante un formulario básico HTML, el servidor comprobara que los datos introducidos seán validos para la base de datos.

Aquí puedes ver un gráfico de la suma de los gastos o ingresos realizos en el año que se haya seleccionado.

Para prácticar y saber realizar cosas que podrían necesitarse en una aplicación real he hecho funcionalidades para exportar los datos de la base de datos ha foramtos JSON y CSV para poder realizar migraciones con la mayor fácilidad possible.

Ejercicio control de usuarios con PHP y SQL

Ejercicio creado con PHP, SQL y Bootsrap para la interfície. Hecho como si fuera un simulacro de una aplicación web de gestión real.

Hice que el cliente pudiera hacer peticiones y consultar el estad de ellas.

El ususario puede indicar el tipo, la localidad, y poner un texto descriptivo.

Aquí en la imagen como puedes observar el usuario puede ver su perfil con claridad, editarlo para adaptarlo a su necesidad y configurar la cuenta.
