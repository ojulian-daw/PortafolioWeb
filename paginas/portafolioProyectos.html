Juegos JavaScript con Phaser 3

Juego de la cucaracha

Juego creado con JavaScript y con el framework de Phaser 3.
Es un juego hecho para mejorar mis conocimientos de programación mediante el uso de un framework para ayudarme a manejar las escenas y las colisiones entre los elementos del canvas.
El juego trata de una cucaracha que tiene que ir comiendo alimento para crecer y esquivar a los insectos más grandes que ella, a medida que va creciendo podrá comerse a otros personajes que van apareciendo por la pantalla.

Juego del caos

Juego creado también con el framework Phaser 3. Hecho para seguir mejorando mi nivel de programación con JavaScript y el uso de escenas y el control de niveles.
El juego consiste en un dinosaurio que debe destruir todo lo que encuentra a su paso y defenderse de las fuerzas militares que intentan detenerlo.

Prácticas con PHP y SQL

Ejercicio de gestor de gastos

Este ejercicio realizo con PHP y SQL sirvio para mejorar mis conociminetos y nivel de programación en la parte de backend.

Puedes insertar el gasto o el tipo de ingreso mediante un formulario básico en HTML. El servidor comprobará que los datos introducidos sean válidos para la base de datos.

Aquí puedes ver un gráfico con la suma de los gastos o ingresos realizados durante el año que se haya seleccionado.

Para practicar y saber realizar cosas que podrían necesitarse en una aplicación real he hecho funcionalidades para exportar los datos de la base de datos a formatos JSON y CSV para poder realizar migraciones con la mayor facilidad posible.

Ejercicio control de usuarios con PHP y SQL

Ejercicio creado con PHP, SQL y Bootstrap para la interfaz. Hecho como si fuera un simulacro de una aplicación web de gestión real.

Hice que el cliente pudiera realizar peticiones y consultar su estado.

El usuario puede indicar el tipo, la localidad y añadir un texto descriptivo.

Como puedes observar en la imagen el usuario puede ver su perfil con claridad, editarlo para adaptarlo a sus necesidades y configurar la cuenta.
