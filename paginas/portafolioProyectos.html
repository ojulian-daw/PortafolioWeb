Juegos JavaScript con Phaser 3

Juego de la cucaracha

Juego creado con JavaScript y con el framework de Phaser 3.
Es un juego hecho para mejorar mis conocimientos de programación con uso de de un framework para ayudarme a manejar las escenas y las colisiones de los elementos de los canvas.
El juego trata de una cucaracha que tiene que ir comiendo alimento para crecer y esquivar a los insectos mas grandes que ella, a medidad que va creciendo podrá comerse a otros personajes que van apareciendo por la pantalla.

Juego del caos

Juego creado también con el framework de Phaser 3. Hecho para seguir mejorarn mi programación con JavaScript y el uso de escenas y control de niveles.
El juego consiste en un dinosaurio que debe destruir todo lo que hay a su paso y defenderse de las fuerzas militares que intentan detenerle.
